HVERDAGS — GITHUB PAGES

1. Les README.md i denne mappen.
2. Opprett offentlig repository «hverdags» på github.com/new.
3. Push prosjektfilene fra VS Code/terminal.
4. GitHub Settings → Pages → Source: GitHub Actions.
5. Supabase → Authentication → URL Configuration: legg inn GitHub Pages-lenken.
6. Opprett egne brukere for deg og kjæresten.

NB: Ikke kjør supabase/schema.sql på nytt.
